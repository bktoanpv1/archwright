# archwright
Bộ khung khởi tạo dự án giúp dự án mới đi đúng hướng từ ngày đầu: tri thức đã chưng cất, agent AI chuẩn hoá vai trò và vòng kiểm chứng PASS/FAIL/BLOCKED. Phần riêng của mỗi lĩnh vực nằm trong một domain pack, thay pack là chuyển sang lĩnh vực khác. Người giữ quyền phán quyết, AI gánh khối lượng.
